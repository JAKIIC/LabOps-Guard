# 个人参赛者介绍

贾奇奇，北京交通大学信息与通信工程硕士，研究方向为面向视觉的语义通信。曾开展 V2V/V2I
车路协同感知与 Transformer 语义分割研究；Cityscapes 实验达到 mIoU 73.76%、Accuracy
93.828%。以作者身份发表 SCI Q2 论文：*Intelligent Cooperative Perception Technology for
Vehicles and Experiments Based on V2V/V2I Semantic Communication*（Electronics，2025）。

技术方向包括 Python、PyTorch、Transformer、深度学习、Multi-Agent、Docker/AI Infra 和
AI 辅助软件工程。本项目由个人独立完成：问题定义、六角色架构、7 个 Skill、受限 Runner、
证据系统、Dashboard、三案例 Demo、开源治理与初赛提交材料。
