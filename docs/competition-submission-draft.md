# 初赛提交文字

## 项目名称

LabOps Guard：可信多智能体实验守护系统

## 500 字以内作品简介

AI 实验指标回退时，普通助手能给建议，却难证明谁执行了什么、是否越权、结果是否可信。LabOps Guard 基于 AgentTeams 构建六角色职责隔离闭环：Commander 拆解事件，Collector 采集白名单证据，Analyst 生成证据约束假设，Planner 制定单变量、有限预算、可回滚计划，Executor 仅在人工批准后调用断网 PyTorch Runner，Auditor 独立复核原始指标、哈希、审批时序、变更范围与 Trace，只有验证通过才能 RESOLVED。主演示中，固定评测因预处理配置漂移从 97.81% 稳定降至 71.88%；系统排除 checkpoint、数据、metric 和随机性，只在沙箱恢复一个配置字段，三次复算回到 97.81%，保护文件均未修改。Matrix、MinIO、Artifact、日志和 SHA-256 链形成可复核证据；依赖缺失安全 BLOCKED、非法 metric 修改拦截回滚等案例独立保留，并沉淀为可搜索案例记忆。
