# 初赛提交文字

## 项目名称

LabOps Guard：可信多智能体实验守护系统

## 500 字以内作品简介

AI 实验指标回退时，普通助手能给建议，却难证明谁执行了什么、是否越权、结果是否可信。LabOps Guard 以 AgentTeams 构建六角色职责隔离闭环：Commander 编排，Collector 白名单采证，Analyst 形成证据约束假设，Planner 制定单变量、有限预算、可回滚计划，Executor 仅在人工批准后调用断网 CPU Runner，Auditor 独立复算指标、保护哈希、审批时序和 Trace；验证未通过不得 RESOLVED。主演示 AT-004 中，固定评测因预处理配置漂移稳定降至 71.875%×3；系统只在沙箱恢复一个配置字段，三次复算达到 97.8124976%×3，六组保护文件哈希不变。Matrix、MinIO、Runner 五件套和 SHA-256 链形成可复核证据；依赖缺失 BLOCKED、非法 metric 修改回滚等案例独立保留。项目开源 7 个版本化 Skill、I/O Schema、Runner 契约和案例记忆，可迁移到训练、评测、数据与发布治理。
