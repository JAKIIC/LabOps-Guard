# LabOps Guard — 本地优先 MVP 范围（mvp_scope.md）

- **任务**：LABOPS-MVP-PLAN-001
- **性质**：规划/规格产出（不写代码、不训练、不测试、不安装依赖、不联网）
- **核心原则**：无证据不诊断，无审批不执行，无验证不闭环
- **输入依据**：POLAR-AUDIT-001-R3 已验收审计证据（5 文件）+ snapshot_verification.json（VERIFIED）
- **约束**：不得把缺失证据猜成事实；不读取排除数据；不提出比赛模型优化方案

---

## 1. 用户（Personas）

| 角色 | 描述 | 关键诉求 |
|------|------|---------|
| **实验负责人（Lab Operator）** | 运行/复现 AI 算法实验（如 Polar baseline），负责结果可信度 | 快速知道"这个实验能不能复现、缺什么、风险在哪" |
| **审计/合规员（Auditor）** | 需要可追溯证据链、审批记录、验证闭环 | 每步有 trace、有哈希、有审批留痕 |
| **AI Worker（Agent）** | 被 LabOps Guard 约束执行受控动作 | 明确哪些可自动、哪些需审批、哪些禁止 |
| **人工审批者（Human Approver）** | 对高风险动作做最终决策 | 决策所需证据充分、默认安全 |

## 2. 问题（Problem）

- 现有实验（Polar baseline 等）的**可复现性证据分散且常缺失**（缺 requirements、缺数据归档、缺预计算产物等，见 evidence_gaps.json 的 10 项 GAP）。
- 无统一机制把"项目快照/运行契约 → 证据采集 → 诊断候选 → 人工审批 → 受控动作 → 验证闭环"串起来。
- 高风险/不可逆动作（安装依赖、下载数据、写文件、跑训练）缺乏默认安全的审批闸门与可追踪记录。

## 3. MVP 目标（做什么）

构建一个**本地优先、CLI + 文件存储**的 LabOps Guard MVP，能对任意项目目录：

1. **快照与契约登记**：记录输入快照哈希、运行契约、配置，形成可复现基线。
2. **证据采集**：扫描允许文件，采集强/弱/缺失证据（引用 `evidence_id`）。
3. **诊断候选**：基于证据产出诊断候选；无证据输出 UNKNOWN/BLOCKED，不臆造。
4. **审批闭环**：read-only 动作自动；写/执行/安装/下载等高风险动作须人工审批；拒绝/失败/验证失败为一等状态。
5. **受控动作**：默认 dry-run、命令白名单、工作目录边界、超时、输出截断与脱敏。
6. **验证闭环**：动作后校验（哈希/退出码/产物存在性），写入 append-only trace。
7. **演示价值**：用 Polar baseline 的真实 evidence gaps 演示"缺失证据识别 + 审批闭环"，不伪造故障、不读比赛测试标签。

## 4. MVP 边界（明确不做 / 非目标）

- **不写正式产品代码**（本任务只产出规格；后续 backlog 才实现）。
- **不训练/不测试模型**、不评估 BER、不优化比赛模型。
- **不读取排除数据**（训练/测试 CSV、私有标签、密钥等）。
- **不联网**、不下载数据（下载动作仅在规格中定义为"须审批 + 模拟适配器"演示）。
- **不做云依赖**：优先本地 Python CLI + 文件存储；无必要不引入云服务。
- **不伪造故障**：演示只展示真实缺失证据的识别，不制造虚假错误。
- **不把缺失证据当事实**：一律 UNKNOWN/BLOCKED 或 evidence gap。

## 5. 竞赛演示价值（Demo Value）

- 以 polar-baseline 为样例项目，一键展示：
  - 13 个允许文件被登记 + 哈希核验（对接 snapshot_verification.json VERIFIED）。
  - 10 项 evidence gaps 被自动识别为 BLOCKED/UNKNOWN（不猜测）。
  - 对"安装 requirements / 下载 zip / 写文件"等动作触发**人工审批**，拒绝/批准路径均可见。
  - 每次决策写入 append-only trace，审批拒绝、动作失败、验证失败均为一等状态。
- 让评审看到：**默认安全、证据驱动、可审计、可复现**的受控实验运维闭环。

## 6. 成功标准（MVP 验收）

- 能对给定项目目录生成：快照登记、证据索引、诊断候选（含 evidence_id）、审批请求、动作执行（dry-run/真实）、验证结果、trace 记录。
- 全部无证据项输出 UNKNOWN/BLOCKED，无一条臆造结论。
- 高风险动作必须经审批才执行；拒绝/失败/验证失败可见且可追踪。
- 输入快照哈希 + 运行契约可追溯，输出可复现。
