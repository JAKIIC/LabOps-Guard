# LabOps Guard synthetic compatibility fixture

LabOps Guard contributors created every file in this directory for deterministic compatibility,
path-safety and evidence-registration tests. The fixture contains no competition dataset, baseline,
notebook, model weight or third-party code. The project licenses these files under Apache-2.0.

The files describe a toy binary classification run. They are test inputs, not performance claims.
Private labels, checkpoints and credentials are absent by design.
