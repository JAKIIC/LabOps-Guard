# 提交样例说明

本压缩包用于说明提交文件格式，包含一个完整的 `submit_sample.csv`，样例中的 bit 全部填为 0，仅用于格式参考，不代表有效模型结果。

正式提交时请只提交单个 UTF-8 编码的 CSV 文件，不要提交本 README，也不要把正式结果打包为 ZIP。

## 文件格式

CSV 第一行为表头，必须严格为：

```text
id,bit_0,bit_1,...,bit_63
```

## 字段要求

- `id`：测试样本编号，必须与公开测试数据中的 `id` 一一对应。
- `bit_0` 到 `bit_63`：解码得到的 64 个二进制比特，只能填写 `0` 或 `1`。

## 评测约束

- 必须覆盖全部测试样本，每个 `id` 只能出现一次。
- 不能缺少测试样本，不能包含未知 `id`。
- 不能添加 `y_i`、`ebno_db` 或其他额外列。
- 排名指标为 BER，比特错误率，数值越低越好。
